# Решения

Что я решил сам, без вопросов владельцу, и почему. Новые решения дописываются в конец.

## Продукт

| Решение | Почему |
|---|---|
| Название Shellter оставлено | Рабочее название из задания; сменить можно в `index.html`, `manifest.webmanifest` и текстах бота |
| Отпустил палец — рак прячется | Управление одним пальцем, а прятки дают решение «есть или переждать» без второй кнопки |
| Призраки других игроков выходят на этапах 6 и 9 с вероятностью 50% | Первый страж должен быть предсказуемым для новичка, босс главы — всегда босс |
| Скамейки запасных жильцов нет | Раковина сама ограничивает сборку; лишнего жильца продают за жемчуг |
| Проигрыш стражу возвращает на привал перед ним | Можно переставить жильцов и попробовать снова, пока есть жизни |
| Второй шанс один на забег | Иначе реклама и Stars покупали бы прохождение |
| Жемчуг при выносе превращается в кораллы (×2), при поражении сгорает | Усиливает выбор «вынести или рискнуть» |
| На сайте гость играет сразу, аккаунт Telegram привязывается позже | Меньше шагов до первой заводи |
| Стартовый экран сайта совмещён с загрузкой | Отдельная посадочная страница замедлила бы вход; кнопки «Играть» и «Открыть в Telegram» есть |

## Техника

| Решение | Почему |
|---|---|
| Сервер — источник истины, клиент шлёт только действия | Защита от подделки наград; заводь сервер проверяет по физическим пределам |
| Общий редьюсер `applyRunAction` и детерминированный бой в `packages/shared` | Один код на сервере, в клиенте, в тестах и в симуляторе баланса |
| Бой считается на сервере, клиент проигрывает журнал событий | Нельзя подделать исход, анимация не расходится с результатом |
| Postgres через Drizzle, для разработки и тестов — PGlite | Запуск одной командой без Docker; тот же SQL и те же миграции |
| Бот — отдельный процесс с внутренним HTTP API | Бот можно вынести на сервер, откуда доступен Telegram |
| Preact + сигналы для интерфейса, PixiJS для сцен | Маленький бандл, DOM для меню и доступности, WebGL для заводи и боя |
| Арт — SVG кодом, запекание в атласы | Нет сторонних ассетов и лицензий, стиль единый, правки через код |
| Звук синтезируется в браузере | Нет аудиофайлов и лицензий, почти не занимает места |
| TypeScript 5.9, Vite 7, Vitest 4, ESLint 9 | Свежие стабильные версии старше 7 дней на момент работы |
| `@types/node` 24 | Версия 22 тянет пакет, который отклоняет политика `trustPolicy: no-downgrade` |
| Playwright 1.63.0 закреплён точно | Совпадает с браузером, установленным в среде разработки |
| Ветка `feat/initial-game` | Так сказано в задании; в `main` ничего не коммитилось |
| Один Dockerfile с целями `server` и `bot` | Общая сборка, два маленьких образа; сервер сам раздаёт клиент и админку |
| Образы по digest, экшены по SHA | Правило владельца для всех его репозиториев |
| Админка — отдельное маленькое приложение на Preact под `/admin/` | Не попадает в бандл игры, закрыта паролем из окружения |

## Монетизация и реклама

| Решение | Почему |
|---|---|
| За Stars продаётся косметика, пропуск, удобства и небольшие наборы кораллов с лимитом раз в день | Запрет на плату за силу; наборы только ускоряют городок и не влияют на бой напрямую |
| Заказ создаётся на сервере, его id — payload инвойса | Идемпотентность по `telegram_payment_charge_id`, возврат знает, что забирать |
| Реклама за интерфейсом `AdProvider`, первой подключена AdsGram | Сеть можно заменить или добавить вторую без правок игры |
| Награда за рекламу только после обращения сети на Reward URL | Клиенту нельзя верить, что ролик досмотрен |
| Дневной предел — 12 показов и свои пределы по местам | Реклама остаётся добровольной и редкой |

## Баланс

Правки по итогам прогонов симулятора описаны в `docs/BALANCE.md`: мягче кривая роста и ярусы фауны, слабее
первые два стража, сильнее пассивки свечения и мягких, слабее рак-богомол.

## Третья итерация

- Жильцов на несколько клеток нет. Соседство даёт ту же головоломку расстановки, но не трогает слияния, лавку
  и формат сохранённого забега.
- Связи считает `packages/shared`, поэтому бой на сервере, подсветка на клиенте и симулятор всегда сходятся.
- Поединок с соперником не стоит жизней и не обязателен: это способ проверить сборку до стража, а не ещё одна
  стена. Соперника подбирает сервер по ближайшей силе с той же ступени; для каждой ступени засеяны боты.
- Трофей и отбивы приходят в отчёте заводи. Сервер проверяет правдоподобие: трофей — один на заводь и не раньше
  восьмой секунды, отбивов — не больше одного на три секунды.
- Течения показаны значками и одним словом. Риск — три деления, без чисел: точные множители игроку не нужны,
  чтобы выбрать.
- На привале убраны заголовки «Выбери одно» и «Лавка», подписи рядов и название экрана: карточки и сетка
  говорят сами.

## Отступления от задания

| Что | Почему |
|---|---|
| Независимого агента-ревьюера не было | Владелец запретил запускать субагентов после двух остановок по лимиту |
| Постоянные визуальные проверки прекращены | Владелец попросил не проверять, а закончить разработку. E2e-сценарий прогнан один раз и проходит |
| Web Push на сайте не сделан | Нужны ключи VAPID и сервис-воркер; уведомления сейчас идут только через бота |
