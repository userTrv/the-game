# Яндекс Игры

Сборка для Яндекс Игр работает без сервера: правила те же (`packages/shared`), но отвечает на запросы
клиент сам (`apps/client/src/local/backend.ts`), а прогресс хранится в облаке Яндекса через `player.setData`.
Покупок за деньги нет. Монетизация — только реклама Яндекса.

## Сборка

```bash
pnpm --filter @shellter/client build:yandex
```

Получится `apps/client/shellter-yandex.zip` (около 3,5 МБ). Скрипт `tools/yandex/pack.mjs` перед упаковкой
проверяет: `index.html` в корне, имена файлов только латиницей без пробелов, распакованный размер до 100 МБ,
нет абсолютных ссылок на `games.s3.yandex.net` и ссылок на Telegram и AdsGram.

Локально без SDK: `pnpm --filter @shellter/client preview:yandex` и открыть http://localhost:5175. Реклама
там заменена заглушкой, сохранение идёт в `localStorage`. С SDK — загрузить архив в черновик и открыть игру
с `?debug-mode=16`.

## Что настроить в консоли разработчика

Готовые тексты, категории, теги, иконка и обложка — в [YANDEX-CONSOLE.md](YANDEX-CONSOLE.md).

1. Включить опцию «Игра использует облачные сохранения» (требование 1.11).
2. Создать лидерборд: техническое название `trophies`, тип «число», сортировка по убыванию, по умолчанию.
   Данные — в [YANDEX-CONSOLE.md](YANDEX-CONSOLE.md#лидерборд).
3. Sticky-баннер Яндекс показывает сам, в коде под него ничего нет.
4. Языки черновика: русский и английский. Название «Shellter» одинаковое в обоих (5.1.3).
5. Возрастной рейтинг: 0+ (насилия, текстов для взрослых и азартных механик нет).
6. Иконка и обложка — отдельный арт, не скриншот (5.6): `pnpm --filter @shellter/art run promo`. Скриншоты —
   из реальной игры (5.1.1.2).

## Как устроено

| Что | Где |
|---|---|
| SDK: загрузка `/sdk.js`, `LoadingAPI.ready`, `GameplayAPI.start/stop`, пауза, реклама, игрок | `apps/client/src/platform/yandex.ts` |
| Локальный бэкенд с тем же API, что у сервера | `apps/client/src/local/backend.ts` |
| Сохранение: `localStorage` сразу, облако не чаще раза в 5 с, сразу — в конце забега и при сворачивании | `apps/client/src/local/save.ts` |
| Боты-соперники, одинаковые на всех устройствах | `packages/shared/src/bots.ts` |
| Косметика за серию просмотров | `AD_UNLOCKS` в `packages/shared/src/liveops.ts` |
| Лидерборд лиги: отправка кубков и топ | `submitTrophies`, `leaderboardTop` в `apps/client/src/platform/yandex.ts` |

Без сервера нет общих таблиц. Поэтому:

- соперники и призраки — только боты;
- событие недели награждает за собственные очки (6000 / 3000 / 1200 / участие) вместо мест;
- Кракена нет: это общий босс, в одиночку он теряет смысл;
- лига — лидерборд Яндекса `trophies` за всё время. Сезонов и среза кубков нет, награда за лигу выдаётся
  один раз при первом выходе в неё. Кубки отправляет только вошедший через Яндекс ID игрок (не чаще раза в
  секунду), гость видит топ и кнопку входа. Таблицу запрашиваем не чаще раза в 30 с (лимит 20 за 5 минут);
- сезонный пропуск — одна бесплатная дорожка, облики на уровнях 5, 12 и 20.

Сохранение занимает около 3 КБ без забега и до 10–20 КБ с забегом (лимит Яндекса — 200 КБ).

## Проверка по требованиям

| Пункт | Как выполнено |
|---|---|
| 1.1, 1.19.1 SDK подключён | `YaGames.init()` до первого запроса к игроку |
| 1.19.2 `LoadingAPI.ready()` | Когда показан первый экран, на котором можно играть |
| 1.19.3 `GameplayAPI` | `start` в заводи, на привале и в бою без открытых панелей; `stop` на рифе, итогах и в меню |
| 1.19.4, 1.3, 4.7 пауза | `game_api_pause` останавливает отрисовку, звук и заводь; `game_api_resume` возвращает |
| 1.2 вход | Только гость или Яндекс ID по кнопке в настройках, с пояснением выгоды (1.2.1) |
| 1.4, 1.13 покупки | Покупок нет |
| 1.9, 1.11 сохранение | Каждое действие пишется в `localStorage` и облако; забег восстанавливается после перезагрузки |
| 1.10.2 скролл | `overscroll-behavior: none`, своя прокрутка панелей |
| 1.6.1.8 долгое нажатие | `user-select: none`, `touch-action: none` |
| 1.12 монетизация | Реклама SDK |
| 2.14 язык | `environment.i18n.lang`; ручной выбор в настройках имеет приоритет |
| 4.1, 4.6 только реклама SDK | AdsGram и свои блоки в сборке не подключаются |
| 4.5, 4.5.1 RV по желанию | Каждая награда за рекламу — по кнопке со значком и словом «Реклама» рядом с наградой |
| Полноэкранная реклама | Только в паузе между забегами, по кнопке «На риф», не чаще раза в 3 минуты |
| 4.5.2 RV не блокирует | Все награды необязательны: косметика, удвоение, сундук, переброс, второй шанс |
| 8.4 внешние ссылки | Ссылки на Telegram, «поделиться» и «позвать друга» в сборке скрыты; `pack.mjs` это проверяет |
| 1.21, 1.22 архив | Проверяет `pack.mjs` |

Проверить руками перед отправкой на модерацию:

- [ ] Игра в черновике с `?debug-mode=16`: индикатор SDK «IT», в консоли нет ошибок.
- [ ] Реклама с наградой даёт награду только после досмотра; при закрытии раньше — нет.
- [ ] Свернуть вкладку во время заводи: звук стихает, заводь на паузе.
- [ ] Прогресс на втором устройстве после входа через Яндекс ID.
- [ ] Поворот телефона и изменение размера окна на десктопе: ничего не обрезано (1.10).
- [ ] Десктоп: соотношение сторон не больше 2:1 (1.6.2.2).

## Где можно добавить рекламу

Сейчас в игре реклама с наградой и полноэкранная после итогов забега.

**Полноэкранная после итогов.** Нажатие «На риф» на экране итогов показывает её перед переходом на риф
(`maybeInterstitial` в `platform/ads.ts`). Не показывается во время обучения и после первых двух забегов, не
чаще раза в 3 минуты и не раньше 3 минут от начала сессии (`platform/interstitial.ts`, тест
`test/interstitial.test.ts`). Экран рифа и его музыка включаются только после закрытия рекламы; на время
показа `game_api_pause` останавливает отрисовку и звук. В локальном превью вместо неё заглушка.

Что ещё можно добавить, по убыванию пользы:

1. **Полноэкранная после боя со стражем**, перед привалом. Тоже пауза, но внутри забега; только если забеги
   длинные (больше 5 минут), иначе мешает темпу.
2. **Sticky-баннер на десктопе справа.** Не перекрывает игру. На телефоне снизу он закроет нижнее меню рифа,
   понадобится отступ; во время заводи его стоит прятать через `hideBannerAdv`.
3. **Новые награды за рекламу:** замена дневного задания, двойные очки события
   на один забег.
